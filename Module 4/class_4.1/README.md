## What you’ll learn

By the end of this class, you should be able to:

- Explain the IR problem setup: given a query **q**, **rank** documents/items by decreasing relevance.
- Define **relevance** (binary vs graded) and why we approximate it with labels/judgments.
- Compute and interpret core metrics: **Precision, Recall, F1, Precision@k, Recall@k**, and rank-aware metrics such as **AP, mAP, MRR.
